# customer-behavior-data-analysis-SQL-Python-PowerBI
Data Analysis project  showcasing customer behavior  analysis  using python, sql and power BI

#📌Project Overview
The goal of this project is to simulate a corporate-grade end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence by:

✅ Data Preparation,Modeling & Exploratory Data Analysis (Python): Clean and transform the raw dataset for analysis.

✅ Data Analysis (SQL): Simulate business transactions, and run queries to extract insights on customer segments, loyalty, and purchase drivers.

✅ Visualization & Insights (Power BI): Build an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

✅ Report and Presentation: Write a clear project report summarizing your key findings and business recommendations. Prepare a presentation that visually communicates insights and actionable recommendations to stakeholders.

## 🐍 Step 1 — Data Loading & EDA

The dataset was imported into Python using **Pandas**.

Initial analysis included:

- Dataset structure inspection using `df.info()`
- Statistical analysis using `df.describe()`
- Missing-value analysis
- Data-type validation
- Understanding customer and purchase behavior

The data was then prepared for further analysis.

---

## 🧹 Step 2 — Data Cleaning

The following cleaning activities were performed:

### Missing Values

Missing values in `Review Rating` were handled using the **median rating of each product category**.

### Column Standardization

Column names were converted to **snake_case** for consistency and easier analysis.

### Feature Engineering

Two new features were created:

- `age_group` — customer ages grouped into meaningful categories
- `purchase_frequency_days` — purchase frequency converted into numeric days

### Data Consistency

The relationship between `discount_applied` and `promo_code_used` was checked. Since they were considered redundant for this analysis, `promo_code_used` was removed.

The cleaned DataFrame was then loaded into **PostgreSQL** for SQL analysis.

---

## 🗄️ Step 3 — SQL Business Analysis

SQL was used to answer important business questions and generate actionable insights.

### Key Analysis Questions

1. **Revenue by Gender**  
   Compared total revenue generated by male and female customers.

2. **High-Spending Discount Users**  
   Identified customers who used discounts but still spent above the average purchase amount.

3. **Top 5 Products by Rating**  
   Identified products with the highest average review ratings.

4. **Shipping Type Comparison**  
   Compared average purchase amounts between Standard and Express shipping.

5. **Subscribers vs. Non-Subscribers**  
   Compared average spending and total revenue between subscribers and non-subscribers.

6. **Discount-Dependent Products**  
   Identified products with the highest percentage of discounted purchases.

7. **Customer Segmentation**  
   Classified customers into:
   - New
   - Returning
   - Loyal

8. **Top 3 Products per Category**  
   Identified the most purchased products within each category.

9. **Repeat Buyers & Subscriptions**  
   Analyzed whether customers with more than five purchases were more likely to subscribe.

10. **Revenue by Age Group**  
    Calculated the revenue contribution of different customer age groups.

## 💡 Business Recommendations

Based on the analysis, the following recommendations were identified:

### 1. Boost Subscriptions
Promote exclusive benefits and incentives to increase customer subscriptions.

### 2. Strengthen Customer Loyalty
Introduce loyalty programs to encourage repeat customers to move into the **Loyal** segment.

### 3. Review Discount Strategy
Evaluate discount policies to balance increased sales with profitability and margin control.

### 4. Promote High-Performing Products
Highlight highly rated and best-selling products in marketing campaigns.

### 5. Target High-Value Customers
Focus marketing efforts on high-revenue age groups and customers using Express shipping.

These recommendations are derived from the project's SQL and dashboard analysis.
